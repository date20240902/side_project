회원가입 시나리오

월승치못 (운영: 인사이트브릿지) · 카카오 로그인 기반 회원가입

1. 서비스 개요

월승치못은 매일 제공되는 월드컵 승부예측 문제 5개에 답하고, 정답 수에 따라 치킨 기프티콘 등 경품을 받을 수 있는 예측 게임 서비스입니다. 별도의 입력 폼 없이 카카오 로그인 한 번으로 회원가입과 로그인이 동시에 이루어집니다.

2. 회원가입 화면 구성

회원가입(시작) 화면에는 개인정보를 직접 입력하는 필드가 없으며, 아래 버튼 한 개만 노출됩니다.

  • [ 카카오로 시작하기 ] 버튼 (탭 시 카카오 로그인 동의 화면으로 이동)

이용자가 직접 이름·연락처 등을 입력하는 별도 가입 폼은 존재하지 않으며, 필요한 정보는 카카오 동의 화면을 통해서만 수집됩니다.

3. 단계별 회원가입 시나리오

  1. 시작 화면 진입
    이용자가 서비스에 접속하면 메인 화면 하단에 "카카오로 시작하기" 버튼이 표시됩니다.
  2. 카카오 로그인 버튼 클릭
    이용자가 "카카오로 시작하기" 버튼을 누릅니다.
  3. 카카오 동의 화면 표시
    카카오 로그인 동의 화면으로 이동하며, 닉네임 동의 항목이 표시됩니다.
  4. 동의 및 인증 완료
    이용자가 닉네임 동의를 하면 카카오 인증이 완료됩니다.
  5. 회원가입 완료 및 서비스 이용 시작
    인증이 완료되면 자동으로 회원이 생성되고, 예측 게임에 바로 참여할 수 있습니다.

4. 회원가입 시 수집하는 개인정보

항목동의 유형수집 목적
닉네임필수서비스 내 닉네임 표시, 순위(리더보드) 표기, 회원 식별

5. 경품 발송 시 추가 정보 수집

경품(치킨 기프티콘 등) 당첨자에 한하여, 기프티콘 발송 및 본인 확인을 위해 필요한 정보(전화번호 등)를 별도 동의를 받아 수집할 수 있습니다. 해당 정보는 발송 목적 달성 후 지체 없이 파기합니다.
